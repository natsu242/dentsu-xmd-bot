📖 Comment utiliser DENTSU-XMD

🔑 Obtenir le code de jumelage

  1. Entrez votre numéro WhatsApp avec le code pays
  2. Cliquez sur Générer le code
  3. Un code à 8 chiffres apparaît (ex: ABCD-EFGH)
  4. Ouvrez WhatsApp → ⋮ → Appareils liés → Lier un appareil
  5. Entrez le code — le bot se connecte !
